# Avernaut Website

Static launch website for **avernaut.com**.

## Structure

- `index.html` — Avernaut corporate homepage
- `inveriq/index.html` — INVERIQ product page
- `styles.css` — shared styling
- `assets/` — Avernaut and INVERIQ brand assets

## Deploy

This is a static site. Upload the folder contents to the document root of `avernaut.com`, or deploy with any static host such as GitHub Pages, Netlify, Cloudflare Pages, or Vercel.
